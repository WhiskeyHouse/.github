**[ignition-mcp](https://github.com/WhiskeyHouse/ignition-mcp)** is a Model Context Protocol (MCP) server for
[Inductive Automation Ignition](https://inductiveautomation.com/) 8.3+, built on the new REST API. It lets AI
agents work directly with Ignition gateways. Written in Python and licensed GPL-3.0, it is our most-starred
open-source project, with 42 stars.

**Highlights**

- **Streamable HTTP or stdio.** A local Streamable HTTP front for `ign mcp serve`, and the same server runs over stdio.
- **Full `ign` tool catalog.** Every `ign` verb is proxied unchanged (92 tools in ign 1.4.0). Credentials and profiles stay in `ign`.
- **Composite workflow tools.** `diagnose_gateway`, `deploy_project`, `push_workspace`, `tag_snapshot`, `find_alarms`, and more.
- **Resources and runbook prompts.** `ign://` resources plus prompts such as `health_check` and `triage_alarm`.
- **Guarded by default.** Destructive verbs still require `confirm: true`.

## 🥃 Who We Are

Whiskey House of Kentucky (WHK) is a distillery and innovation hub in Bardstown, Kentucky. We combine
traditional craftsmanship with modern digital technology to support our operations, manufacturing, and
customer engagement.
